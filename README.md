## Run Locally

To run the website on your computer:

1. Clone the repository:

   ```bash
   git clone https://github.com/aseemraheem/Aseemraheem.github.io.git
   ```

2. Open the project folder in Visual Studio Code.
3. Install the **Live Server** extension if you haven't already.
4. Open `index.html`.
5. Right-click and select **Open with Live Server**.

Your browser will open a local version of the portfolio.

## Deployment

This website is hosted using GitHub Pages.

To publish updates:

1. Commit the updated website files to the repository's `main` branch.
2. Open the repository's **Settings → Pages**.
3. Configure deployment from `main` and the root folder (`/(root)`).
4. Wait for GitHub Pages to publish the changes.

The live website is available at:

**[https://aseemraheem.github.io/](https://aseemraheem.github.io/)**
